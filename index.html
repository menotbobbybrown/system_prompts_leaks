Connect to Your AI Agent

1-Click configurations for DeepSeek Harness, Claude Desktop, Cursor, and Windsurf.

Add to ~/.dsh/mcp.json or your project's .dsh/mcp.json: 

{
  "mcpServers": {
    "system_prompts": {
      "command": "npx",
      "args": ["-y", "system-prompts-mcp", "serve"]
    }
  }
}

Add to claude_desktop_config.json: 

{
  "mcpServers": {
    "system_prompts": {
      "command": "npx",
      "args": ["-y", "system-prompts-mcp", "serve"]
    }
  }
}

Terminal CLI Commands

Explore, search, and run system prompts directly from command line.

Command Description Copy
npx system-prompts-mcp list List all 100+ discovered system prompts
npx system-prompts-mcp list Anthropic Filter prompts by vendor (Anthropic, OpenAI, Cursor, DeepSeek, etc.)
npx system-prompts-mcp get cursor/cursor Print the full system prompt markdown to stdout
npx system-prompts-mcp search "reasoning" Search prompts by keyword or domain
npx system-prompts-mcp serve Start the stdio Model Context Protocol (MCP) Server for agents
